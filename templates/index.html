💡 Troubleshooting Tips

Common Issues:

  • Cannot reach Jira server: Check that your Jira URL is correct (e.g., https://yourcompany.atlassian.net)
  • Authentication failed: Verify your email and API token. Generate a new token at Atlassian API Tokens
  • Project not found: Ensure the project key is correct (case-sensitive) and you have access to it
  • PDF extraction failed: Your PDF might be image-based or encrypted. Try a text-based PDF
